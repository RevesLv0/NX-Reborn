embedded defaults: mode 4; CIS 106/110, CPU 102/105 and ISP 106/110. The live
accessor selects preference group 4 and returns mapped base + `0x200` + ID offset.
Its ID high word `0x85600000` also matches the configured `/dev/mem` physical
mapping base. Prefman's own embedded temperature defaults are separately zero.
Neither table establishes actual camera NVD contents or runtime initialization.
NVD backing slots and byte offsets are now mapped, with error and unit limits
explicitly retained.

[Independent review](../analysis/architecture/THERMAL_POLICY_REVIEW_RUN009.md)
