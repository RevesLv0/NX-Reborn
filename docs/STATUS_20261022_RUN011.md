## Results

[Media and DCF ownership](../analysis/architecture/MEDIA_DATABASE_RUN011.md)
establishes a concrete app object/vtable/callback boundary into the DCF list.
Filename generation already adds an item and increments the list count before
a file-write completion. Metadata updates, DCF deletion and platform media-row
registration have separate implementations and results. A row, reserved item
or notification cannot stand in for successful capture or persistence. Three
vendor libraries are newly loaded; the existing camera app supplies caller
evidence. [Independent review](../analysis/architecture/MEDIA_DATABASE_REVIEW_RUN013.md)
supports all nine bounded claims and retains rollback/IPC/runtime limits.

[Packaged preferences](../analysis/architecture/PACKAGED_PREFERENCES_RUN011.md)
connect eleven individual defaults to exact full-bundle slices using original
script sector offsets, complete SHA comparisons and magic/size/CRC checks. The
system slice at `0x180000` contains temperature mode/threshold words
`4,106,110,102,105,106,110`, matching factory defaults. These packaged bytes are
distinct from libprefman's zero embedded table and from live NVD contents.
Original Thumb main/load code also shows that the script's bare `prefman load`
invocation reaches a usage branch, rather than proving an all-ID load. Boot
preload remains a separate path. [Independent review](../analysis/architecture/PACKAGED_PREFERENCES_REVIEW_RUN012.md)
reproduces the packaged-data and CLI findings; it does not claim every init
command semantic was independently reviewed.

[Kernel card producers](../analysis/architecture/KERNEL_CARD_EVENTS_RUN011.md)
bind the platform driver to four exact vendor EVENT strings. All four carry
platform `ACTION=remove`, including `EVENT=sdcard_insert`; this is distinct from
block-device removal. Shared error suppression, local queued-bit order and
selected MMC retry/reset paths are concrete, with untested emission results and
no capture/file identity. [Independent review](../analysis/architecture/KERNEL_CARD_EVENTS_REVIEW_RUN013.md)
supports the four bounded categories and supplements the device-kset binding.
The packaged kernel's actual active role remains unobserved.
