# 서브 에이전트 사용 기록 — 2026-10-21

현재 펌웨어 역설계 채팅의 전체 활동 페이지와 각 에이전트의 결과 기록을 조회해, 고유 에이전트 17개를 확인했다. 단계별로 RUN002 6개, RUN003 6개, RUN004 5개다. 같은 에이전트에 준 후속 작업은 별도 에이전트로 중복 집계하지 않았다. 아래 내용은 에이전트의 담당 범위이며, 해당 기능 전체의 역설계 완료를 뜻하지 않는다.

## 모델 기록의 한계

- RUN004 5개는 생성 호출에서 모델 override를 생략하여 부모 모델을 상속했다. 정확한 실행 모델 ID는 현재 제공되는 활동 기록과 thread 메타데이터에 노출되지 않는다.
- RUN002/RUN003 12개는 활동·결과를 확인했지만, 복원 가능한 기록에 생성 시 모델 선택 인자가 없어 모델 선택 방식을 확정하지 않았다.
- 부모 모델 상속은 정확한 제품명이나 버전명이 아니다. 추정 모델명을 실제 사용 모델로 기록하지 않는다.

## 이후 보고 방식

서브 에이전트를 사용할 때 역할·선택한 모델 또는 상속 여부·선택 이유를 알리고, 작업 종료 시 결과·검증·미해결 사항을 정리한다. 모델 override를 명시했다면 요청한 모델 ID를 기록한다. 실제 실행 모델 ID가 별도로 확인되지 않으면 요청 모델과 실제 확인 상태를 구분한다. 상속할 때는 상속 사실을 기록하며 정확한 모델명이 노출되지 않으면 그 한계를 명시한다.

앞으로 각 기록에는 고유 에이전트명, 담당 범위, 모델 설정, 추론 노력 설정(알 수 있을 때), 주요 산출물 및 결과를 남긴다. 이 요청을 처리하기 위해 새 서브 에이전트를 생성하지 않았다. 과거 실적과 앞으로의 배치 계획을 구분한다.
