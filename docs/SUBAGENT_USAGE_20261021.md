## 이후 보고 방식

서브 에이전트를 사용할 때 역할·선택한 모델 또는 상속 여부·선택 이유를 알리고, 작업 종료 시 결과·검증·미해결 사항을 정리한다. 모델 override를 명시했다면 요청한 모델 ID를 기록한다. 실제 실행 모델 ID가 별도로 확인되지 않으면 요청 모델과 실제 확인 상태를 구분한다. 상속할 때는 상속 사실을 기록하며 정확한 모델명이 노출되지 않으면 그 한계를 명시한다.

앞으로 각 기록에는 고유 에이전트명, 담당 범위, 모델 설정, 추론 노력 설정(알 수 있을 때), 주요 산출물 및 결과를 남긴다. 이 요청을 처리하기 위해 새 서브 에이전트를 생성하지 않았다. 과거 실적과 앞으로의 배치 계획을 구분한다.
