## Verification

The [evidence](../analysis/evidence/card-events-run007.json) and
[generation manifest](../manifests/ghidra-card-run007.json) preserve original source
hashes, exact input association, full run receipts, selected C and mode/reference
queries. Original-byte checks covered **71 code windows (29 ARM / 42 Thumb,
7,067 instruction rows)** and four data-only blocks. Saved TMode contexts were
queried using the new `ExportAddressReferences.java` and isolated runner; manual
Thumb targets additionally use their odd descriptor pointers as mode evidence.

All code windows were mapped back through original PT_LOAD and decoded again;
bytes, instruction rows and artifact/manifest hashes matched. The six bounded
primary-agent claims are in [the review ledger](../manifests/review-run007.json).
**64 host tests, compileall and whitespace checks passed.** No target executable,
camera access, mounting, formatting or installation occurred.

Failed preliminary reference queries are retained: a direct launch attempted an
unwritable default Ghidra configuration path, then a nonrecursive selector found
no nested program. The isolated recursive runner succeeded. Zero function
matches for the unrecovered getter/setter names are also retained explicitly;
they are not mislabeled as a decompiler failure or absent code.
