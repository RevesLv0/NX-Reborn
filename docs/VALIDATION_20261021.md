# 검증 및 독립 검토 — 2026-10-21

## 실행 결과

- Python 도구 회귀 11개 통과: 동일 크기 변조, 잘림, 경로 이탈, 심볼릭 링크,
  중복 식별자, 기존 목록의 잘못된 검증 승격, 출력 변조·누락·미완료·다른 실행 결과 거부.
- Python 도구 구문 검사 통과.
- 고정 버전 Ghidra·전체 JDK·Python 의존성의 bootstrap 확인 통과.
- 확보한 29개 원본 파일의 크기·SHA-256을 기대값과 대조해 모두 일치.
- 13개 ELF의 Ghidra 저장 프로젝트를 열어 증거를 내보내고, 각 산출물의 해시·크기·행 수·
  입력 식별·실행 ID를 검증했다. 전체 코드 의미 분석 완료를 뜻하지 않는다.
- libsif close 함수는 별도의 ELF 파서·Capstone으로 80바이트 전체를 독립 디스어셈블했다.
- 기존 원본 ZIP·전체 파일시스템은 이번 세션에 다시 내려받지 못했으므로 새 무결성 검증 완료로 표시하지 않았다.

## 서브 에이전트 검토와 보완

분석 도구 검토, 전체 구조 지도, 저장 경로 독립 검증을 병렬로 수행했다.

| 검토 사항 | 적용한 보완 |
|---|---|
| 취소된 출력이 완료로 보일 가능성 | 최종 게시 직전 취소 검사, 완료 요약을 마지막에 기록 |
| Ghidra 비실행 섹션 주소의 잘못된 ELF 변환 | 기본 주소 공간·실제 적재 메모리만 변환, 나머지는 null |
| 데이터 심볼을 함수로 디스어셈블할 가능성 | STT_FUNC·실행 가능 PT_LOAD·정의 유일성 검사 |
| 매니페스트 경로 이탈·중복 | 상대 경로·경계·일반 파일·심볼릭 링크·식별자 유일성 검사 |
| 오래되거나 손상된 출력의 검증 누락 | 실행 UUID, 산출물 SHA-256·바이트·JSON 행 수 검사 |
| 디컴파일 형식의 과신 | 함수 서명 출처와 ABI 미검증 표시 |
| 선택한 일부 함수만 디컴파일한 사실 누락 | 선택 패턴·일치 수·예산으로 생략한 수·실패 수 기록 |

Ghidra 프로젝트별로 단일 작성자를 사용한다. 내보내는 동안 해당 출력 폴더를 최종
스냅샷으로 취급하지 않으며, 실행 종료 및 검증 후에만 보관한다.

## 남아 있는 한계

직접 호출 그래프는 가상 함수·동적 로딩·IPC의 모든 경로를 포함하지 않는다.
Ghidra가 추론한 타입과 호출 규약은 원본 선언이 아니다. 함수·문자열 집계에는 thunk와
메타데이터가 포함될 수 있다. 실기기 관측·전체 원본 재추출·드라이버 하드웨어 실행은 미수행이다.
